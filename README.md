# 🌱 FocusTree  
**“집중할수록 내 나무가 자란다!”**  
포커스 타이머 기반의 목표 관리 서비스로, 사용자가 집중한 시간을 바탕으로 나무가 성장하고, 열매를 수확하며 목표 달성도를 시각적으로 확인할 수 있는 **집중 관리 어플리케이션**입니다.

---

## 📌 주요 기능

### 🌿 1. 집중 타이머(포커스 모드)
- 설정한 목표에 맞춰 **집중 시간을 기록**합니다.  
- 집중 시간이 쌓이면 나무가 성장하며, 단계별로 시각적 변화가 나타납니다.  
- **방해금지 / 뽀모도로 모드** 지원.  
- 오늘의 총 집중 시간을 홈 화면에서 직관적으로 확인할 수 있습니다.

### 🌳 2. 나무 성장 시스템
- 집중할수록 나무가 **새싹 → 묘목 → 나무 → 울창한 나무**로 성장합니다.  
- 하루 집중량은 3D 타일 농장에 나무 형태로 배치되어 시각적으로 확인 가능합니다.  
- 지속적인 사용을 유도하는 몰입형 성장 시스템.

### 📊 3. 통계 & 분석
- **일 / 주 / 월 / 연 단위** 집중 시간 분석 제공.  
- 시간대별 집중 그래프 및 목표별 집중 비율 시각화.  
- 목표 달성률 기반의 상세 통계 기능.

### 🎯 4. 목표 관리
- 사용자는 *공부, 업무, 운동, 취미* 등 카테고리로 목표를 생성할 수 있습니다.  
- 각 목표마다 **독립된 나무 종류 선택** 가능.  
- 목표 달성 여부 체크 및 주간/월간 목표 관리 기능 제공.

### 🍎 5. 열매 보상 시스템
- 일정 집중 시간 달성 또는 목표 달성 시 **열매 보상** 획득.  
- 열매는 카테고리별로 서로 다른 종류가 제공됩니다.  
- 인벤토리에서 열매를 확인하고 활용(향후 기능 연동 예정) 가능합니다.

### 🛒 6. 스토어
- 집중을 통해 얻은 포인트(예: "그루")로 **새로운 나무 스킨** 구매 가능.  
- 포인트 부족 시 자연스럽게 안내되는 UX 제공.
